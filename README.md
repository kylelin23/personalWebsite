## Description
I designed and developed a full-stack personal portfolio website. Features include: 
- An interactive map game that rendered 20+ animated entities.
- A physics-based pathing system, enabling entities to autonomously navigate obstacles in real time.
- RESTful APIs using Next.js and MongoDB to serve blog posts, projects, and real-time comments.

## Tech Stack
- React
- TypeScript
- Node.js
- Next.js
- MongoDB
